# KWOLI TOOL - Quick Start Guide

## 🚀 Быстрый старт

### Шаг 1: Установка

**Для Windows:**
```bash
install.bat
```

**Для Linux/Mac:**
```bash
chmod +x install.sh
./install.sh
```

**Или вручную:**
```bash
pip install -r kwoli_tool/requirements.txt
```

### Шаг 2: Запуск

```bash
python run.py
```

### Шаг 3: Использование

1. Вы увидите анимированный логотип KWOLI с градиентом
2. Нажмите ENTER чтобы перейти в главное меню
3. Выберите функцию (1-15) или нажмите Q для выхода

## 🔧 Требования

- Python 3.7 или выше
- pip (менеджер пакетов Python)
- Интернет подключение (для функций поиска)

## 🛠️ Установленные зависимости

- **requests** (v2.31.0) - для HTTP запросов к API
- **colorama** (v0.4.6) - для поддержки ANSI-цветов в Windows

## 🔐 Важные советы по безопасности

1. **Никогда** не используйте реальные личные данные из приложения
2. Используйте сгенерированные пароли для защиты аккаунтов
3. Используйте временные почты для ненадежных сервисов
4. Прочитайте мануал по анонимности перед использованием
5. Используйте VPN при поиске конфиденциальной информации

## 🐛 Решение проблем

### Проблема: "No module named requests"
**Решение:**
```bash
pip install requests
```

### Проблема: Цвета не отображаются в Windows
**Решение:**
```bash
pip install colorama
```

### Проблема: API не отвечает
**Решение:** Некоторые API имеют рейт-лимиты. Подождите несколько секунд перед следующим запросом.

### Проблема: "Permission denied" при запуске install.sh
**Решение:**
```bash
chmod +x install.sh
./install.sh
```
