# KWOLI TOOL - Advanced Search & Generation Tool

🎯 **KWOLI TOOL** - это мощный Python CLI инструмент для поиска информации и генерации данных с красивым интерфейсом.

## Особенности

✨ **Красивый интерфейс:**
- Анимированный стартовый экран с градиентным логотипом KWOLI
- Цветной интерфейс с ANSI-кодами
- Удобное меню для навигации

🔍 **15 встроенных функций:**
1. 🔍 Поиск по IP адресу
2. 📱 Поиск по номеру телефона  
3. ✈️ Поиск по Telegram
4. 🌐 Поиск по веб-сайту
5. 👤 Поиск по никнейму
6. 🎮 Поиск по Discord
7. 🎯 Поиск по Roblox
8. 🕷️ WebCrawler
9. 🔁 Создание прокси конфигураций
10. 🎭 Генератор вымышленной личности
11. 📧 Генератор временной почты
12. 🔐 Генератор паролей (обычные, длинные, фразы)
13. 🏦 Генератор BAN-слов
14. 🛡️ Мануал по анонимности в интернете
15. ⭐ Зал славы (полезные приложения и ссылки)

## Установка

### Требования
- Python 3.7+
- pip

### Инструкции

1. **Клонируйте или скопируйте проект:**
```bash
cd kwoliTOOL
```

2. **Установите зависимости:**
```bash
pip install -r kwoli_tool/requirements.txt
```

Или вручную:
```bash
pip install requests colorama
```

## Использование

### Запуск приложения

```bash
python run.py
```

или

```bash
python -m kwoli_tool.main
```

### Работа с приложением

1. **Стартовый экран**: Вы увидите анимированный логотип KWOLI с градиентом (зелено-синий)
2. **Нажмите ENTER**: Для перехода в главное меню
3. **Выберите функцию**: Введите номер (1-15) или Q для выхода
4. **Следуйте инструкциям**: Каждая функция попросит необходимые данные

## Описание функций

### Функции поиска (1-8):
- **IP Search**: Получит информацию о локации, провайдере и координатах IP
- **Phone Search**: Анализ номера телефона, определение страны и типа
- **Telegram**: Поиск пользователя Telegram (требуется Bot Token для полного функционала)
- **Website**: Анализ веб-сайта, проверка статуса и заголовки
- **Nickname**: Поиск никнейма на популярных платформах (GitHub, Twitter, Reddit, Instagram)
- **Discord**: Поиск пользователя Discord (требуется Bot Token)
- **Roblox**: Поиск пользователя Roblox через официальный API
- **WebCrawler**: Краулинг веб-сайта, извлечение ссылок

### Функции генерации (9-13):
- **Proxy Generator**: Генерирует конфигурации прокси-серверов (HTTP, HTTPS, SOCKS5, SOCKS4)
- **Fake Person**: Генерирует полные данные вымышленной личности (ФИО, возраст, профессия, телефон)
- **Temp Email**: Генерирует временные адреса электронной почты с паролями
- **Password Generator**: Создает безопасные пароли разной сложности и парольные фразы
- **Ban Word**: Генерирует уникальные слова для использования в качестве альтернативных никнеймов

### Справочная информация (14-15):
- **Anonymity Manual**: Подробное руководство по анонимности в интернете
- **Hall of Fame**: Ссылки на полезные приложения (VPN, мессенджеры, браузеры и т.д.)

## API и источники

Приложение использует следующие бесплатные API:
- **ipapi.co** - для информации по IP адресам
- **Roblox API** - для поиска пользователей Roblox
- Различные веб-сайты для проверки никнеймов

## Требования к интернету

Большинство функций требуют подключения к интернету. Некоторые функции (генерация паролей, вымышленных личностей, BAN-слов) работают оффлайн.

## Ограничения и кастомизация

### Добавление API ключей:
Некоторые функции требуют API ключей. Вы можете добавить их в `config.py`:

```python
API_CONFIGS = {
	'telegram_token': 'YOUR_BOT_TOKEN',
	'discord_token': 'YOUR_BOT_TOKEN',
	'custom_api': 'YOUR_API_KEY'
}
```

### Модификация функций:
Каждая функция находится в отдельном модуле и может быть легко изменена или расширена.

## Проблемы и их решение

### Ошибка: "No module named 'requests'"
```bash
pip install requests
```

### Цвета не отображаются в Windows
Приложение автоматически работает с Windows. Если цвета не отображаются, попробуйте:
```bash
pip install colorama
```

### API не отвечает
Некоторые API имеют рейт-лимиты. Подождите несколько секунд перед следующим запросом.
