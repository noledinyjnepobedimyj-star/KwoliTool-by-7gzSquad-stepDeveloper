## 📋 Файлы проекта

### Основные
- `run.py` - ***точка входа***
- `test_kwoli.py` - проверка функциональности
- `demo_logo.py` - демонстрация логотипа

### Папка kwoli_tool/
- `main.py` - главное приложение
- `config.py` - конфигурация (включая ASCII_LOGO)
- `ui/animation.py` - анимация и визуальные эффекты
- `ui/colors.py` - работа с цветами
- `modules/searchers.py` - 8 функций поиска
- `modules/generators.py` - 5 функций генерации
- `modules/utilities.py` - справочные материалы

### Документация
- `README.md` - полная инструкция
- `QUICKSTART.md` - быстрый старт
- `ASCII_LOGO_UPDATE.md` - описание обновления
- `PROJECT_SUMMARY.md` - итоговая сводка

### Установка
- `install.bat` - для Windows
- `install.sh` - для Linux/Mac
- `requirements.txt` - зависимости

## 🎮 Управление в приложении

1. **Стартовый экран** → Просмотр анимированного логотипа
2. **Нажмите ENTER** → Перейти в главное меню
3. **Выберите 1-15** → Выполнить функцию
4. **Или Q** → Выйти из приложения
